# 게임용 역사 국기 아이콘

직접 그린 로컬 SVG입니다. 작은 화면의 가독성을 위해 문장·용·코끼리·별 등을 픽셀 형태로 단순화했습니다. 정밀한 국기 도안 복제본이 아닙니다. 외부 이미지나 이모지를 내려받지 않습니다.

대한제국 태극기, 청 황룡기, 러시아 백청적기, 일본 일장기, 영국 유니언기, 프랑스 삼색기, 독일제국 흑백적기, 이탈리아 왕국 사보이 문장기, 오스만 성월기, 시암 백상기, 브라질 공화국기 및 미국 성조기를 표시합니다. 오스트리아-헝가리는 공동 국기가 없던 상황을 고려해 1869년 공동 상선기를 대표 아이콘으로 사용합니다. 작은 문장과 태극기의 괘는 도식화했습니다.

미국은 1908년 3분기부터 46성 버전으로 표시합니다. 그 이전은 45성입니다. 분기 단위 게임이므로 1908년 7월 4일 변경을 그 분기에 반영합니다.

확인 자료:
- Smithsonian, 미국 국기 연혁: https://www.si.edu/spotlight/flag-day/flag-facts
- 오스트리아-헝가리 공동 상선기: https://www.crwflags.com/fotw/flags/ah~ensnn.html
- 시암 1855~1916 백상기: https://www.crwflags.com/fotw/flags/th1855.html
