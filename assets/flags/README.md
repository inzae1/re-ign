# 실제 역사 국기 자료

Wikimedia Commons에서 공개된 SVG를 내려받아 원본 그대로 사용합니다. 직접 그린 간략 아이콘을 교체했습니다. 모든 파일의 출처·저자·라이선스·원본 해시는 [sources.json](sources.json)에 기록했습니다. 자료에 표시된 라이선스는 모두 Public domain입니다.

대한제국은 1899년 자료에 근거한 태극기 재현본입니다. 당시 태극기의 세부 형태는 다양했으며 현대 표준 태극기를 소급 적용하지 않았습니다. 일본은 1870~1999년 도안, 청은 1889~1912년 황룡기, 미국은 1908년 3분기부터 45성에서 46성으로 바뀝니다.

오스트리아·헝가리에는 공통 국기가 없었으므로 오스트리아의 흑황기와 헝가리의 문장기를 별도 이미지로 병기합니다. 공동 상선기를 국가 국기로 표시하지 않습니다. 이탈리아는 왕관 문장이 있는 당시 정부용 기를 대표로 사용합니다. 원본 비율을 유지하며 화면 안에 맞춰 표시합니다.
