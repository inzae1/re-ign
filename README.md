# RE:IGN

## 실행

Node.js 20 이상에서 다음 명령으로 실행합니다.

```sh
npm start
```

브라우저에서 http://localhost:4173/ 을 여세요. 타이틀을 터치하거나 Enter를 누르면 시작합니다. 진행은 브라우저에 자동 저장됩니다.

```sh
npm test
```

현재 게임 제목은 **RE:IGN**입니다. 타이틀은 국가·연도 부제 없이 모든 국가 시나리오에 공통으로 사용합니다. 첫 플레이 시나리오는 대한제국입니다. 이전 설계 문서와 저장 식별자에는 개발 당시 이름이 남아 있습니다.

# 멸망의 시대 — 대한제국 간단 모드

현재 규칙은 **STRATEGY-WAR-DIPLOMACY.md**, 역사 사건 목록과 자료는 **HISTORY-EVENTS.md**입니다. DESIGN-SIMPLE.md는 단순화 단계의 설계 이력입니다. REDESIGN.md는 이전 복잡한 버전의 설계 이력입니다.

## 실행

Node.js 18 이상. 이 폴더에서 `npm start` → http://localhost:4173/ 을 엽니다. 추가 패키지 설치나 빌드는 없습니다. `npm test`로 규칙 검증을 실행합니다.

## 플레이

국고·민심·주권만 보고 매 분기 무작위로 올라온 **세금 징수·철도 건설·구휼 시행·군비 확충 등 9종 정책 중 3개**에서 하나를 고릅니다. 선택 한 번으로 다음 분기까지 진행합니다. 역사 사건 26종(선택형 12·소식 14)이 실제 연도/분기에 등장합니다. 선택형 사건은 대응을 고르고, 소식은 확인 버튼 없이 읽고 지나갈 수 있습니다. 연간 일반 사건도 역사 선택형 사건이 없는 경우에 등장합니다. 1910년에 주권 35 이상, 민심 25 이상이면 생존합니다. 도중 어느 하나가 0이면 패배합니다.

도시는 짧은 정보만 보여줍니다. 1904년 사건에서 항만 방어를 선택하면 전쟁 상황실에서 진지 방어·반격·보급·휴전을 진행합니다. 봉쇄·전비·보급 고갈·시설 피해·도시 점령이 국가 자원과 수입에 영향을 주고 종전 뒤에도 남습니다. 외교 공관에서 청·러시아·일본과 관계를 개선해 통상·동맹을 맺고 전시 지원을 요청할 수 있습니다. `http://localhost:4173/?preview=war`에서 저장 없이 전쟁을 바로 체험할 수 있습니다. 건설·장수·부대·연구 관리와 별도 분기 종료는 없습니다. 정책 아래 수치는 결산까지 포함한 실제 변화량입니다. 기존 복잡한 버전의 저장을 지우지 않고 간단 모드는 별도 저장합니다.

## 구현

- `src/game.js`: 세 자원, 9종 무작위 정책, 철도 수입, 전선·보급·봉쇄 전쟁, 연간 사건, 생존 판정, 저장
- `src/app.js`: 지도 도시 정보, 선택 카드, 사건과 기록, 도움말
- `src/sea.js`: 움직이는 증기선 4척, 항적/증기, 포격 연출
- `style.css`: 금빛 테두리와 한글 명조/고딕, 세로형 화면
- `assets/east-asia-map.png`: 생성된 픽셀 지도. 정적 개략도 위에 실시간 Canvas 배/전투 연출을 겹침
- `assets/reference-screen.jpg`: 사용자가 제공한 참고 화면. 작은 아이콘을 CSS 스프라이트로 사용
- `assets/fonts/`: 현재 글꼴 Wanted Sans Variable 및 라이선스 (과거 글꼴도 이력으로 보관)
- `preview-simple.png`: 현재 실행 화면

자동 검증 17개 통과. 브라우저에서 철도→군비→관세 정책으로 전투 3분기 진행 및 방어 성공 확인. 모바일 실기와 장기 밸런스 검증은 남아 있습니다. 과거 화면과 설계 파일은 이력으로 남겨 두었습니다. 모든 사건·수치는 역사에서 착안한 게임용 가정입니다.

글꼴은 공식 Wanted Sans 배포본을 검색·확인해 로컬 적용했습니다. 제목/버튼 720~800, 본문 450~500으로 통일하고 자간을 조정했습니다. 출처: https://github.com/wanteddev/wanted-sans

- `src/history.js`: 날짜·설명·출처·가상 대응을 분리한 역사 사건 26종
- `HISTORY-EVENTS.md`: 전체 사건표와 확인 자료
- `http://localhost:4173/?preview=history&event=hague1907`: 저장 없는 역사 사건 미리보기

- `src/strategy.js`: 국가별 관계/협약/동맹, 전선/보급/전비/봉쇄/점령/전후 복구 규칙
- `src/strategic-ui.js`: 별도 외교 공관과 전쟁 상황실 화면
- `STRATEGY-WAR-DIPLOMACY.md`: 현재 전쟁·외교 규칙과 범위
- 외교 미리보기: http://localhost:4173/?preview=diplomacy (저장하지 않음)

모바일 전쟁 UI는 작전/동맹 지원/전황·복구 탭으로 압축했습니다. 기본 전쟁 화면은 390×844 및 360×740 브라우저 크기에서 주요 작전까지 한 화면에 표시됩니다. 최신 화면: `preview-war-mobile.png`.

전시에는 붉은 상단 경보·교전 표식·공격 경로를 표시합니다. 작전 버튼은 문양과 입체 테두리로 구분합니다. 최신 전시 화면: `preview-war-alert.png`.

## 전체 화면 픽셀 지도
지도는 전체 화면에서 드래그와 핀치/휠로 탐색합니다. 오른쪽 `세계`는 전체 지도, `대한`은 시작 위치로 돌아갑니다. 아래 국정·외교·전쟁 패널은 제목을 눌러 접거나 펼칩니다. 자세한 조작과 지형 데이터 출처는 [WORLD-MAP.md](WORLD-MAP.md)를 참고하세요.

세계 주요 12개국 모두 사절·통상·동맹·전시 지원이 가능합니다. 외교 화면의 국가 선택 메뉴 또는 지도 오른쪽 `국가`에서 상대를 고르세요. 국가별 효과는 [STRATEGY-WAR-DIPLOMACY.md](STRATEGY-WAR-DIPLOMACY.md)에 있습니다.

## UI 스타일
`modern-ui.css`에서 둥근 네이비 패널·민트 강조색·코랄 전쟁 표시를 통일합니다. 로컬 Wanted Sans의 본문 450, 버튼 550, 제목 650 굵기를 사용하고 글자 그림자와 금색 입체 테두리를 제거했습니다. 블러 없이 정적 반투명 배경을 사용합니다. 390×844 및 360×740에서 지도 메뉴·외교·전쟁·정책 화면을 확인했고 작은 화면의 가로 넘침은 없습니다.

## 첫 타이틀 화면
《멸망의 시대》 / 부제 ‘대한제국, 1900’. 기존 픽셀 지도 그림을 배경으로 사용하며 클릭·탭 또는 Enter/Space로 진입합니다. 저장한 분기와 사건·전쟁을 이어가고, 분기를 소비하거나 새 원정으로 초기화하지 않습니다. 새로고침하면 타이틀을 다시 표시합니다. 실제 세계지도 데이터와 애니메이션은 타이틀을 통과한 뒤 시작합니다. 390×844 화면과 키보드 진입, 기존 1904년 3분기 원정 보존을 확인했습니다.

타이틀 배경은 새로 생성한 `assets/reign-world-title.png` 세계지도 일러스트를 사용합니다. 생성 도구와 최종 프롬프트는 `assets/reign-world-title-prompt.md`에 기록했습니다. 모바일에서는 모든 대륙이 보이도록 배경을 잘라내지 않고 표시합니다.

타이틀 표기는 RE:IGN이며, 시작 문구 아래의 저장 연도 안내는 표시하지 않습니다. 이어하기는 기존 저장을 그대로 사용합니다.
