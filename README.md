# RE:IGN

[바로 플레이](https://inzae1.github.io/re-ign/)

모바일 세로형 픽셀 역사 전략 로그라이크. 첫 시나리오는 대한제국 1900~1909년입니다.

## 현재 규칙

- 국고(원)·민심·군사력을 관리합니다. 군사력은 실제 전쟁의 아군 전력입니다.
- 매 분기 세 가지 정책 중 하나 또는 외교·작전·반란 대응을 실행합니다. 분기가 바뀌면 계절 타이틀만 짧게 표시합니다. 결산과 세계 소식은 펼쳐 읽고 국내 사건은 국정에서 대응합니다.
- 군사력이 낮으면 재정·군사 여력이 있는 일본·러시아·청이 침공할 수 있습니다. 동맹·우호 관계는 침공을 억제합니다.
- 민심 저하는 반란으로 이어집니다. 구휼·회유·진압으로 수습할 수 있습니다. 국고 고갈은 체불·군사력·민심 하락을 일으키며 이후 재정을 확보하면 상환합니다.
- 12개국도 분기마다 세입·유지비·군비·민심과 역사 사건을 결산합니다. 외교 화면에서 현황과 근거 자료를 볼 수 있습니다.
- 수도 함락·반란군 정부 전복 시 패배합니다. 1910년 군사력 30·민심 25 이상이고 전쟁·반란을 수습하면 생존합니다.

군사력·민심은 게임 지수, 국고는 게임 내 원 환산액입니다. 실제 역사 통계로 제시하지 않습니다. 상세 규칙·사건·출처는 [COUNTRY-SIMULATION.md](COUNTRY-SIMULATION.md), 세계 소식 자료는 [WORLD-HISTORY.md](WORLD-HISTORY.md)를 참고하세요. 이전 설계 문서는 개발 이력입니다.

## 로컬 실행

Node.js 20 이상. 추가 패키지 설치나 빌드 없이 실행합니다.

```sh
npm start
npm test
```

http://localhost:4173/ 에서 플레이합니다. 진행은 브라우저에 자동 저장되며 기존 주권 모델 저장은 군사력 모델로 변환됩니다. 금액은 유지됩니다. 전투 중 저장은 저장된 아군 전력을 기준으로 이관합니다.

`?preview=war`, `?preview=diplomacy`, `?preview=history&event=hague1907`, `?preview=crisis`, `?preview=unrest`는 본편 저장을 바꾸지 않는 확인용 화면입니다.

## 자료와 에셋

국기 원본·저자·공개 라이선스는 assets/flags/README.md와 sources.json에 기록했습니다. 게임용 수치와 사건 대응은 가상 전개입니다. 실제 역사 소식에는 출처 링크를 제공합니다.

### 선전포고
외교에서 12개 국가 중 대상을 선택해 선전포고합니다. 군사력 35 이상, 동원비 200,000원이 필요하며 1분기와 첫 교전 전비를 사용합니다. 민심 −6, 다른 국가 관계 −8, 대상국 동맹·통상 파기(동맹 배신 시 군사력 −3)가 적용됩니다. 원정전은 기존 작전·보급·동맹 지원을 사용하며 승리 시 상대 잔여 국고에서 최대 200,000원 배상금을 받습니다. 원정 패배는 철군으로 처리하고 국내 도시 점령과 구분합니다. 같은 국가와 종전 후 4분기 동안 재선전포고할 수 없습니다.

### 국가 선택·도시 기습
지도에서 국가명 또는 영토를 터치하면 경계를 강조하고 주요 도시 3곳을 표시합니다. 하단 국가 카드에서도 도시를 선택할 수 있습니다. 경계는 기존 현대 지도 자료를 묶은 게임용 근사이며 1900년의 정확한 국경선은 아닙니다. 12개국·36개 도시를 지원합니다.
도시 작전의 기습 공격은 280,000원, 항구 대상 해군 포격은 320,000원입니다. 군사력 35 이상이 필요하고 원정 준비비 외 첫 분기 전비도 발생합니다. 선전포고 없이 공격하지만 즉시 원정전이 시작되며 민심 −10, 다른 국가 관계 −12, 대상국 조약 파기를 적용합니다. 기습 공격은 상대 군사력 최대 −8·국고 최대 −60,000원, 포격은 군사력 최대 −5·국고 최대 −120,000원을 주고 우리 군사력도 각각 −4/−3 소모합니다. 적 전선 전력 추가 −8은 첫 공격의 기습 효과이며, 국가 지표와 별도로 적용합니다. 항공 전력 대신 기존 원정·해군 작전을 사용합니다. 도시 영토 병합은 구현하지 않습니다.
전쟁 중에는 상대국·교전 분기·양측 전력이 담긴 상단 경고 띠를 항상 표시하고, 붉은 국정 패널·전쟁 버튼으로 상황실에 접근할 수 있습니다.

### 분기 전환 연출
정책·외교·작전 후에는 날짜만 중앙에 1.6초 표시하고 패널을 닫은 대한제국 지도로 돌아갑니다. 터치나 Escape로 즉시 넘길 수 있습니다. 긴 분기 확인 화면과 확인 버튼은 없애고, 자원 증감은 ‘결산·지난 행동’, 세계 소식은 제목이 보이는 접힌 항목에서 확인합니다. 역사 사건은 지도 위 짧은 알림을 눌러 국정 패널에서 대응하며 긴 배경 설명은 펼쳐 읽습니다.

### 화면 정보 정리
국정은 세 가지 정책과 결산 포함 예상 자원 변화를 우선 표시하고 배경·세계 소식·결산을 하나의 접힌 영역으로 모았습니다. 외교는 행동을 먼저, 상대국 수치와 역사는 펼쳐 읽도록 배치했습니다. 비활성 행동도 해제 조건을 읽을 수 있게 대비를 유지합니다. 도시 공격은 준비비·예상 국고 변화·상대 피해·우리 손실을 줄별로 구분합니다. 작전과 외교의 예상 국고 변화는 기본 비용·분기 수입/전비·체불 상환을 포함하되, 이후 교전·새 사건·반란은 제외합니다.

분기 전환 시에는 날짜 연출 **전부터** 조작 패널을 숨기고 `map` 화면으로 전환합니다. 일반 분기에 국정 안건 알림을 자동 표시하지 않습니다. 국정·외교·전쟁은 사용자가 지도 버튼을 눌러 열며, 대응할 사건·반란·종료 결과에만 짧은 지도 알림을 남깁니다. 전쟁 화면은 양측 전력 비교·보급/사기·네 작전을 중심으로 보여주고 상세 비용 규칙은 전황 탭에 접어둡니다.
